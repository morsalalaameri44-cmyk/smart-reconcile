# SmartReconcile MVP

## تشغيل سريع
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload
```

ثم افتح:
http://127.0.0.1:8000

بيانات الدخول التجريبية:
- username: admin
- password: admin123

## قواعد المطابقة
- المبلغ: مطابق تماماً (شرط إلزامي)
- التاريخ: فرق أقصى يوم واحد
- اسم العميل: مطابقة/تشابه
- المستخدم: عامل مساعد
- لا يسمح باستخدام عملية بنك واحدة في أكثر من مطابقة مؤكدة

## ملاحظة
هذه نسخة MVP مناسبة للتسليم السريع. قبل الاستخدام الإنتاجي يجب:
- استبدال الدخول التجريبي بمصادقة آمنة وقاعدة بيانات.
- إضافة ربط أعمدة يدوي/ذكي للملفات غير القياسية.
- تشغيل OCR على الخادم وتثبيت Tesseract للصور.
- إضافة صلاحيات وسجل تدقيق وتشفير وتخزين آمن للملفات.
